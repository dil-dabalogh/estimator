# Infrastructure Management

This directory contains AWS infrastructure deployment and management tools for the Estimation Tool.

## Chore CLI Tool (Recommended)

A modern Python CLI/TUI tool that provides a unified interface for all infrastructure management tasks. It supports both direct command invocation and interactive menu navigation.

### Quick Start

```bash
cd infrastructure/chore
pip install -e .
chore --help
chore interactive  # Launch interactive menu
```

### Example Commands

```bash
# Deploy
chore deploy backend config
chore deploy frontend

# IP Management
chore ip list
chore ip add-current

# Diagnostics
chore diagnose api

# Bedrock Agent
chore bedrock setup
```

See [chore/README.md](chore/README.md) for complete documentation.

## Script Naming Convention

Scripts follow a consistent naming pattern to indicate their purpose:

- `deploy-*.sh` - Deployment scripts for the main application
- `setup-*.sh` - Initial setup/creation scripts for AWS resources
- `update-*.sh` - Scripts to update existing AWS resources
- `diagnose-*.sh` - Diagnostic and troubleshooting scripts
- `test-*.py` - Test scripts for validating AWS resources

## Available Scripts

### Deployment

- **`deploy.sh`** - Main deployment script for the Estimation Tool API
  - Builds and deploys the SAM application
  - Usage: `./deploy.sh`

### Bedrock Agent Setup

- **`setup-bedrock-agent.sh`** - Creates a new AWS Bedrock Agent
  - Sets up the agent with personas from `../personas/combined_agent_instruction.txt`
  - Creates necessary IAM roles and permissions
  - Generates `bedrock-agent-config.sh` with agent IDs
  - Usage: `./setup-bedrock-agent.sh`

- **`setup-bedrock-agent-permissions.sh`** - Grants IAM permissions for Bedrock Agent testing
  - Attaches necessary policies to your IAM user/role
  - Verifies agent execution role permissions
  - Usage: `./setup-bedrock-agent-permissions.sh`

- **`setup-mcp-action-groups.sh`** - Configures MCP (Model Context Protocol) action groups
  - Sets up Atlassian MCP integration (Confluence, Jira)
  - Configures Lambda functions for MCP proxying
  - Usage: `./setup-mcp-action-groups.sh`

- **`update-bedrock-agent.sh`** - Updates an existing Bedrock Agent's instructions
  - Reloads persona instructions from file
  - Re-prepares the agent
  - Usage: `./update-bedrock-agent.sh [agent-id] [region]`

### Diagnostics

- **`diagnose-authorizer.sh`** - Diagnoses Lambda authorizer setup
  - Checks authorizer configuration
  - Verifies IP range settings
  - Views recent authorization logs
  - Usage: `./diagnose-authorizer.sh`

- **`diagnose-bedrock-agent.sh`** - Diagnoses and fixes Bedrock Agent issues
  - Checks agent status and preparation
  - Verifies IAM role permissions
  - Validates foundation model access
  - Automatically fixes common issues
  - Usage: `./diagnose-bedrock-agent.sh`

### Testing

- **`test_bedrock_agent.py`** - Python script to test Bedrock Agent invocation
  - Validates agent responses
  - Tests MCP integration
  - Usage: `python3 test_bedrock_agent.py`

## Configuration Files

- **`template.yaml`** - AWS SAM CloudFormation template
  - Defines all AWS resources (Lambda, API Gateway, DynamoDB, etc.)
  - Contains parameter definitions and outputs

- **`samconfig.toml`** - SAM CLI configuration
  - Stores deployment parameters and preferences
  - Auto-generated by `sam deploy --guided`

- **`bedrock-agent-config.sh`** - Generated Bedrock Agent configuration (not tracked in git)
  - Contains agent ID, alias ID, and region
  - Source this file to set environment variables: `source bedrock-agent-config.sh`

## Common Workflows

### Using Chore CLI (Recommended)

#### Initial Setup

```bash
cd infrastructure/chore
pip install -e .

# Deploy backend
chore deploy backend config

# Add your IP to whitelist
chore ip add-current

# Deploy frontend
chore deploy frontend

# Set up Bedrock Agent (optional)
chore bedrock setup
```

#### Interactive Mode

```bash
chore interactive
```

Navigate through menus to access all functionality with guided prompts.

#### Updating Agent Instructions

```bash
# Edit personas/combined_agent_instruction.txt
chore bedrock update
```

#### Troubleshooting

```bash
chore diagnose api
chore diagnose authorizer
chore diagnose bedrock
```

## Environment Variables

Key environment variables used by scripts:

- `AWS_REGION` - AWS region (default: us-west-2)
- `BEDROCK_AGENT_ID` - Bedrock Agent ID (set by bedrock-agent-config.sh)
- `BEDROCK_AGENT_ALIAS_ID` - Bedrock Agent Alias ID (set by bedrock-agent-config.sh)
